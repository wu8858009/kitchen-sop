# 廚房 SOP 食譜及倍數計算系統

同一套介面，兩種版本：

| 版本 | 位置 | 資料存放 |
|---|---|---|
| PWA 網頁版（手機／平板／電腦） | `web/` | 瀏覽器 IndexedDB（各裝置各自一份） |
| Windows 版 | `dist/廚房SOP.exe` | `%APPDATA%\KitchenSOP\data.json`，每日自動備份到 `backups\`（保留 30 份） |

兩版可用「設定 → 匯出／匯入備份」互相搬移資料（JSON）。

## Google 雲端同步
「設定 → Google 雲端同步」連到你自己的 Google 試算表（Apps Script 後端 `cloud/Code.gs`）後，所有裝置讀寫同一份資料；
本機資料仍保留作離線快取，連上網自動同步。設定步驟見 [cloud/設定說明.md](cloud/設定說明.md)。
可在 `web/config.js` 填入預設網址，各裝置就只需輸入存取密碼。

## 功能
- 食譜：分類、照片、食材（可分組；只填名稱的列當小標題，例如「出餐」）、SOP 步驟（計時、重點標示）、備註；支援批次貼上食材／步驟
- SOP 主資料（導覽列「SOP」）：仿紙本單點 SOP 表單（考核欄、食材明細、操作步驟、照片、注意事項）；自動計算 採購份量 = 使用份量 ÷ (1−耗損%)、成本 = 採購份量 ÷ 規格 × 進價（自動換算單位）、成本合計、淨售價↔含稅售價（5%）、毛利與毛利率；可從食譜帶入、從單價表帶入規格與進價，列印成 A4 表單
- 倍數計算：輸入倍數（可用「/3」「÷3」「1/3」除以幾倍）或目標份量；點食材旁的 ⚖ 輸入現有量（可用不同單位，如「5 台斤」）自動反推倍數
- 單位：g/kg/台斤/兩/lb/oz、ml/L/大匙/小匙/杯；顯示模式可選自動、原單位、公制、台制
- 成本：單價表（可用台斤、kg、顆…計價，自動換算），顯示每道菜總成本與每份成本
- 越南文：小抄卡片內的菜名、食材、用量、步驟、備註會在中文下方附越南文（可在小抄「內容與版面」關閉）；食譜內容用 Google 翻譯自動產生（需連線 Google 雲端），編輯食譜時的虛線框可修改
- 小抄：挑選食譜與倍數，濃縮成精簡卡片（食材用量、重點步驟、備註、成本可選），兩欄／單欄／一頁一張與字級可調，可加自訂文字卡，按住 ⠿ 拖曳調整卡片順序，列印後貼在工作台；手機按「列印小抄」會產生 A4 PDF，從分享選單列印／存檔／傳 LINE
- 備料單：多道菜各自設倍數，合併相同食材的總量與成本，可列印
- 計時器：多個同時進行，時間到會響鈴、震動；鈴聲可在設定選 6 種內建鈴聲或上傳自己的音檔，並調整音量；手機可開「螢幕恆亮」

## 快捷鍵
按 F1（或設定頁「⌨ 快捷鍵」）可看完整清單。常用：Alt+1～6 切換分頁、Ctrl+F 搜尋、Alt+N 新增、Ctrl+S 儲存／同步、Ctrl+P 列印、Ctrl+E 編輯食譜、＋／－ 調整倍數、Esc 關閉視窗或取消編輯。照片可按 Ctrl+V 貼上或拖曳進視窗（編輯食譜＝食譜照片；SOP＝照片辨識或設為照片；SOP 列表＝從照片建立）。

## PWA 部署
線上版：https://wu8858009.github.io/kitchen-sop/ （手機開啟後「加入主畫面」即可離線使用）

GitHub Pages 讀的是 `gh-pages` 分支（內容 = `web/` 資料夾）。修改後在 `main` commit，再執行：

```
git subtree split --prefix web -b gh-pages && git push origin gh-pages
```

本機測試：`cd web && python -m http.server 8765` 後開 http://127.0.0.1:8765 。
修改 JS/CSS 後請同步調整 `index.html` 的 `?v=` 與 `sw.js` 的 `CACHE` 版本。

## Windows 版輸入法
點進輸入框時自動切換輸入法：菜名、食材、步驟、備註、搜尋等文字欄切到「中文」，數量、倍數、價格等數字欄切到「英數」（注音模式下數字鍵會打出注音）。越南文欄位與單位欄不切換。
（由 `desktop/main.py` 的 `set_ime` 透過 WM_IME_CONTROL 設定；網頁版無法控制輸入法。）

## Windows 版打包
需要 Python、pywebview、PyInstaller、PySide6（只用來產生圖示）。

```
python build.py
```

測試用環境變數：`KITCHENSOP_DATA=<資料夾>`（改用獨立資料夾、略過單一執行個體限制）、`KITCHENSOP_SELFTEST=<結果.json>`（自動操作後寫出結果並關閉）。
